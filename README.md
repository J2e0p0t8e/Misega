⛩️ MISEGA - Plateforme E-commerce Manga
MISEGA est un projet de boutique en ligne spécialisée dans la vente de mangas, conçu avec une attention particulière portée au design, à l'immersion et aux performances. L'objectif est de proposer une expérience d'achat premium grâce à une interface utilisateur sophistiquée, des animations fluides (line-art, 3D) et une architecture robuste.

🚀 Technologies & Stack
Ce projet s'appuie sur une architecture monolithe moderne, garantissant réactivité et maintenabilité :

Back-end : Laravel (Architecture MVC)

Front-end : Vue.js (Composition API) avec Inertia.js

Styling : Tailwind CSS

Base de données : PostgreSQL

Outils : Génération assistée par IA (Antigravity)

✨ Fonctionnalités Clés (MVP)
Catalogue de mangas immersif avec effets de parallaxe et 3D.

Système de gestion de base de données relationnelle (users, mangas, volumes, orders).

Design minimaliste "Dark Mode" avec accents rouges et typographie calligraphique.
